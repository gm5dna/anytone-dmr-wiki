# Analog APRS will not work

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Analog_APRS_will_not_work.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Analog_APRS_will_not_work.pdf) Hub item 90.

This is most likely down to a bad/corrupted Codeplug.

You need to do this with your codeplug

1. Export all CSV (a.)
2. In the CPS click on File NEW
3. Import all CSV (a.)
4. Skip going over Optional Settings for now (b.)
5. Save this codeplug so you can find it again
6. MCU reset the radio and set date and time
7. Send this new codeplug to the radio
8. Test your APRS now and it should work

a. How to [Export and Import All CSV](../cps-firmware/export-and-import-all-csv.md)

b. Optional Settings – [Settings I Use](../getting-started/settings-i-use.md)
