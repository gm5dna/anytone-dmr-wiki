# Faster GPS Lock

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Faster_GPS_Lock.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Faster_GPS_Lock.pdf) Hub item 71.

## In the CPS

**CPS → Optional Settings → GPS/Ranging**

| Setting | Value |
|---|---|
| GPS Mode | **GPS** |

![CPS GPS Mode field set to GPS](../assets/img/faster-gps-lock/img-01.jpeg)

*GPS Mode = GPS.*

## In the radio

**Menu → GPS → GPS Mode**

Set to **GPS**.
