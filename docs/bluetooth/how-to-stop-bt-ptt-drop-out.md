# How to stop BT PTT drop out

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/How_to_stop_BT_PTT_drop_out.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/How_to_stop_BT_PTT_drop_out.pdf) Hub item 64.

1. Turn BT on in Radio.
2. Turn Radio OFF.
3. BT PTT hold down the PTT.
4. Turn radio on and wait for the BT PTT to connect.
5. Let go off the BT PTT.

Now you can use the BT PTT and it should not drop out.
