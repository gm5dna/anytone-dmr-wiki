# Access Talk Groups

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Access_Talk_Groups.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Access_Talk_Groups.pdf) Hub item 109.

You have a few options via an Anytone Radio to call up a Talk Group.

## Option 1 – Add as a Channel

Add as a Channel to the radio: see [Add Talk Groups](add-talk-groups.md).

## Option 2 – Dial the Talk Group

1. Press and hold the **0** key (new window opens: Private ID).
2. Press the **#** key = Talk Group ID.
3. Type in the Talk Group Number (2350 UK, 91 World Wide etc).
4. **PTT** and now you're on 2350.

**CPS → Optional Setting → Digital Fun**

| Radio | Setting | Value |
|---|---|---|
| 868 | Group Call Hold Time | 30mins |
| 878 and 578 | Dial Group Hold | 30mins |

## Option 3 – List key

1. Click on the **List** key (RED).
2. Scroll down or up till you find the Talk Group you wish to use.
3. Press **PTT** and now you're on that Talk Group.

You need to have the Talk Group added to the CPS – Talk Groups (see Option 1).

**CPS → Optional Setting → Digital Fun**

| Radio | Setting | Value |
|---|---|---|
| 868 | Group Call Hold Time | 30mins |
| 878 and 578 | Group Call Hold Time | 30mins |

## Option 4 – Menu key

Is the same as Option 3 but going via the Menu Key.

**Menu Key (Green) → Talk Groups → TG List**

## Option 5 – Last Call Reply

**CPS → Optional Setting → Key Function** – set a key to **LastCal Reply**.

**CPS → Optional Setting → Digital Fun**

| Radio | Setting | Value |
|---|---|---|
| 868 | Group Call Hold Time | 30mins |
| 878 and 578 | Dial Group Hold | 30mins |

With Digi Moni turned on for Single or Double Slot, when a call comes in on another Talk Group/Private Call you press the Function Key and the radio is now locked to that Talk Group/Private Call.

Just **PTT** and you're on that Talk Group or Private Call.
