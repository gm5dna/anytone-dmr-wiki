# Digital Contact list doesn't show up on the radio

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Digital_Contact_list_doesnt_show_up_on_the_radio.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Digital_Contact_list_doesnt_show_up_on_the_radio.pdf) Hub item 2d.

The Digital Contact list does not show in the radio. (Hidden)
It is only used to show users info on RX, rather than the DMR ID Number.

If you add any users to the "Contact Talkgroup List", they will show in the radio.
You only need to add users, if you know them, and wish to talk to them via Private call or send a SMS to them.
