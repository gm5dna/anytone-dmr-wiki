# How to import Codeplug from another radio

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/How_to_import_Codeplug_from_another_radio.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/How_to_import_Codeplug_from_another_radio.pdf) Hub item 25,  26.

Anytone 868, 878 and 578 to an Anytone 868, 878 and 578.

**Anytone now recommend this method.**

1. Go to the NEW CPS of the radio you wish to import the old/other codeplug to.
2. Open the old/other codeplug.
3. Save that new codeplug for that radio.
4. Close the CPS.
5. Open the CPS again.
6. Make any changes required.
7. Save the codeplug again.
8. Send to radio.

Now you have imported your codeplug from one radio to another.

CSV files should only be used:

- on the same version of codeplug, CPS and firmware, or
- if you want to do a mass edit via the CSV file, or
- if you have been seeing [strange or odd things happening with radio](../troubleshooting/strange-or-odd-things-happening.md).
