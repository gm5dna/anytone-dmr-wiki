!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/How_to_import_Codeplug_from_another_radio.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/How_to_import_Codeplug_from_another_radio.pdf) Hub item 25,  26.

Anytone 868, 878 and 578
to a
Anytone 868, 878 and 578

**Anytone now recommend this meathead.**

Go to the NEW CPS of the radio you wish to import the old/other Codeplug to.
Open the old/other Codeplug
Save that New Codeplug for that radio.
Close the CPS
Open the CPS again
Make any changes required
Save Codeplug again
Send to radio

Now you have imported your Codeplug from one radio to another

CSV files should only be used on the same version off Codeplug, CPS and Firmware.
