# AES256/ARC4 encryption CSV Export/Import

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/AES256-ARC4_encryption_CSV_Export-Import.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/AES256-ARC4_encryption_CSV_Export-Import.pdf) Hub item 17a.

## Limitations

1. You can no longer export to CSV. You can export a blank CSV with headers.
2. You cannot read back from radio to the CPS.

## How to use

1. When filling in the keys into the CPS, take the blank CSV exported and fill in the keys to that at the same time.
2. Now you have built a CSV file of all your keys. Keep this in a safe place.
3. Next time, all you need to do is import the CSV, rather than adding back to the CPS one by one.
