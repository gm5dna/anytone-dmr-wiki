# Motorola RAS and CAP+

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Motorola_RAS_and_CAP.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Motorola_RAS_and_CAP.pdf) Hub item 124.

Anytone has a licence from Motorola to make DMR Radios.
The licence does not include RAS or CAP+

*We have checked with Motorola, currently the RAS and CAP+ function is not included in our license, it will not be possible to add this function to our radios.*

RAS and CAP+ is proprietary to Motorola, and is only offered in Motorola radios.
If you need RAS or CAP+, then buy a Motorola radio that offers it.

RAS = Restricted Access to System
CAP+ = Capacity Plus
