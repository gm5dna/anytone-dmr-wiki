# 578 Missing Icons

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/578_Missing_Icons.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/578_Missing_Icons.pdf) Hub item 48.

> Hi guys,
>
> Correcting missing or corrupt icons on the D578 is easy, it uses the same icon update pack that the D878 uses. The current icon file is Icon v1.20, which was included as part of 878 firmware v1.11 release.
>
> The process is:
>
> 1. Turn D578 off.
> 2. Connect USB cable to radio and PC.
> 3. Hold in **P1** & **Channel** dial button, while turning the radio on.
> 4. Almost immediately the screen displays "UPDATE MODE" – if not, try again.
> 5. Start up 578 CPS, select appropriate COM port under **Set → Set COM** menu.
> 6. Go to **Tool → Firmware Upgrade** (yes, that is correct).
> 7. Point the software to the 878 Icon v1.20 file.
> 8. Again, select the appropriate COM port.
> 9. Hit **Write** button. Writing should take no more than 55 seconds.
> 10. Power off the D578, remove USB cable, power on. All done, no need to reset.
>
> Thanks,
> Jason

Download this file and unzip. All you need is the folder called [D878UV_ICONV1.20_0226](http://www.geoo.de/AnytoneDL/D878UV_V1.11%20official%20release.zip).
