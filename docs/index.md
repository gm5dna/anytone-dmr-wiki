# AnyTone DMR UK Wiki

A searchable copy of **Norman Williams'** guide to the AnyTone AT-D168UV, AT-D868UV, AT-D878UV,
AT-D890UV and AT-D578UV radios, first published at
[hamradiosouthernrepeaters.co.uk/anytone-dmr.html](external-resources.md)
and used by the [AnyTone AT-D168/868/878/890UV & D578UV UK User Group](https://www.facebook.com/groups/1798919343492370/)
since 2018.

!!! quote "Norman Williams, AnyTone UK User Group, 22/11/2026"
    I will be closing down my website in June 2027. […]
    If anyone wants to copy the Anytone page and host it, feel free to do so.

Norman announced that his site would close, so every guide is kept here as a Markdown page, with the original PDF
archived alongside it. External links have an **archive** link to an Internet Archive copy in case the original disappears.

## Finding things

- **Know the item number from the old page?** Use the [original index](hub-index.md). It keeps Norman's numbering (1–190).
- **Have a particular radio?** The [radio model tags](tags.md) list every page for each model.
- **Otherwise** use the search box, or browse by topic in the menu.
