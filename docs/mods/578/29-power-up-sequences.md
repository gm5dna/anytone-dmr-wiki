There are several power up sequences which involve holding down buttons to invoke certain modes on the 578, as follows:

| Buttons held down on power up | Mode entered |
|---|---|
| **MENU** + **EXIT** (pressed together just after power *OFF*) | Main firmware update mode (red LED blinks) |
| **P1** + dial | Display icon update mode |
| **P2** + dial | Reset menu |
| **P3** + dial | GPS module test mode |
| **P4** + dial | TEST MODE, where you can select operational bands ("modes") and/or adjust alignment parameters, but only if this has been first enabled by AT Options software |
| **P5** + dial | Test mode with BHT (Bluetooth) turned on |
| **P6** + dial | Update mode for LinkBoard (Bluetooth). No updates available as yet. |
| **MENU** + dial | DSP SCT update mode |
| **EXIT** + dial | GPS signal strength (RSSI) test mode |
| Mic **PTT** + dial | Update mode for Hand-Soft - to update the mini MCU running the controls of the microphone. No updates available as yet. |

Some of these sequences require you to hold the buttons for up to ten seconds before they take effect.

## Test mode access levels

The test mode (**P4** + dial) has three levels of access:

1. Normally, test mode will be completely inhibited as delivered by the factory.
2. With ’band select’ test mode, you will only be able to select MODE to change operational frequency bands of the radio.
3. In full unlocked test mode, some degree of calibration / alignment is possible from the front panel of the radio for deviation levels, power output levels, received signal strength indication (RSSI) levels, squelch levels, frequency fine setting and more.

See [Enabling full test / self adjustment mode](39-full-test-mode.md) for more detail.
