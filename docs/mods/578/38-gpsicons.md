**Alternate GPS icons to download (578 only)**
With thanks to Francesco IK8JHL
Notice how the GPS ’reception OK’ icon is red? Red is often used as an indication of failure, so using a red icon to indicate good GPS reception can be confusing. Francesco has corrected this by changing the GPS icon completely, and making the icon green when reception is good. Here are the icons that have been changed:

![](../../originals/images/578Mods/NewGPSicons.jpg)

These are written to the radio using the UPDATE MODE:

1.  
2.  Download & unzip this alternate GPS ICON_V1.22_M1 pack (1.2Mb) from one of these locations:
    [Download via Mega](https://mega.nz/file/Sw90waQA#PkT5IPD02FXeIQ5erJA5efOCbmI23sjwxiVnG9oKnjw)
    [Download via Google Drive](https://drive.google.com/file/d/1u7iYltNRPXeQ2kOht_oeWK1zR5Mkfs0s/view?usp=sharing)
    [Download via Sabercat host](https://sabercathost.com/a20l/ICON_V1.22_M1.3.zip)
3.  Connect the radio to your computer with the programming cable
4.  Turn on the 578 while holding down DIAL & P1 buttons until UPDATE MODE is displayed
5.  Start up the CPS software and navigate to menus: Tool \> Firmware Upgrade (while this selection doesn’t specifically mention ’Icon’ this IS definitely the correct process to use). If a new Firmware Update window doesn’t automatically open, you can manually find and launch the QX_Update_Firmware.exe to achieve this
6.  Select Open Update File and point the software to the new Icon pack file ICON_V1.22_M1.spi file and click write
7.  The update takes just over 40 seconds to write, power cycle the radio normally once finished
