By default, the CPS programming software comes with an English.HPT file that provides the help guidance text in the bottom window. This English.HPT file can be found in a subdirectory called Help in your CPS installation folder.

Replacing the English.HPT with the following download will give that help text in French. This is updated for v1.15.

!!! note
    The file name must remain as English.HPT, so don’t let that confuse you.

I do not have any other help text files other than French, sorry.
