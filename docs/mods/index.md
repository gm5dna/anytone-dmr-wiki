## Jason's tools

Jason's original download site (anytonetechzone.byethost7.com) has gone offline. The mods pages now link to
copies of his tools recovered from DB1IG's mirror. They're listed with SHA-256 checksums in
[SOURCE.txt](../originals/anytonetechzone/SOURCE.txt). These copies can't be checked against Jason's originals,
so scan the `.exe` files before running them. No copy could be found of the 868, 878, 6X2, DJ-MD5 or DJ-MD5X
fast-defrost files, so those links no longer work.
