# Hotspot Users BER rate V2

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/PDF/Hotspot-Users-BER-rate.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/PDF/Hotspot-Users-BER-rate.pdf)

!!! warning
    Your BER rate **must** be under **1%** when you TX. If not you have packet loss and others will RX you as broken up.

| Hotspot | What to change |
|---|---|
| Pi-star | Change your RXOFFset |
| BlueDv | Change QRG |
| Openspot | Run AutoCal |

To find how to make changes, Google it.

If using via a mobile phone you should restart your phone before using hotspot. This way you get the best internet connection.

Please share this PDF to all DMR FB Groups. Email it to new users and friends starting out.

It is quite clear that many do not know how to set the BER rate on a hotspot, leading to bad audio and dropouts while talking.

You would not run a RF rig with a high SWR. Hotspots need to be set up for a BER rate under 1% to as low as you can get it. **0.5% BER loss is normal and most will never get 0%.**

If you have 3 DMR radios, all might require a different setting to keep the BER rate low or you will be lucky and find one setting to cover all your DMR radios.

Bad internet can also give you a high BER rate.
