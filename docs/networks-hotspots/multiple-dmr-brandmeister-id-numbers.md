# Multiple DMR BrandMeister ID Numbers

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/PDF/Multiple-DMR-BrandMeister-ID-Numbers.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/PDF/Multiple-DMR-BrandMeister-ID-Numbers.pdf)

You only need one ID number.
[Registration](https://www.dmr-marc.net/cgi-bin/trbo-database/register.cgi) for a ID Number.

When using Multiple DV Devices.

OpenSpot, ZumSpot or DVMega

Does not work on a DV4mini

You will have your 7 Dig ID that will be used in all your DMR radios

In the DV devices if running more that one you can now do this.

First Device your 7 dig ID.
Second Device add your 7 dig ID but add 00 to 99 on the end to make a 9 Dig ID
More Devices take the last number up by 01
(This will give you 100 IDs)

Each Hotspot must have its own separate frequencies or Colour Code

This is to stop Looping

[434.000  Low Power Non-NoV Personal Hot-Spot usage](https://rsgb.org/main/operating/band-plans/vhf-uhf/432mhz-band/)
[438.800  Low Power Non-NoV Personal Hot-Spot usage](https://rsgb.org/main/operating/band-plans/vhf-uhf/432mhz-band/)

Recommendation of Frequencies to use. Bandwidth of 25 kHz

## Simplex HotSpot Freq

434.6000  to  434.9800
438.8000  to  440.0000

## Duplex HotSpot Freq

434.6000  to  434.9800
438.8000  to  440.0000
or
9 Meg split
430.2750  to  430.7625
439.2750  to  439.7625
