## UHF / VHF DV SIMPLEX

**DMR -** Time Slot 1 , Colour Code 1 , Talk Group 9

The time slot, color code and talk group are based on what’s in the majority of code plugs

**Radio channel should be set to DMO/Simplex**

**NXDN –** Talk Group 9 , Very narrow – 6.25khz , RAN 1

Very narrow - 6.25khz - because anyone using IDAS or NXDN96 won't hear you.
