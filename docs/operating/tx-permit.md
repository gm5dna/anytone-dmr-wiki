# TX Permit

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/TX_Permit.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/TX_Permit.pdf) Hub item 42.

When working a repeater or hotspot – Anytone DMR 868 – 878 – 578:

| Setting | Value |
|---|---|
| TX Permit | Channel Free |

This is the only one that will let you know if someone has grabbed the slot before you. If you key and get "Chan Busy!" then you know it is in use by another.

!!! warning
    If set to Always you could be left talking to yourself (doubling).
