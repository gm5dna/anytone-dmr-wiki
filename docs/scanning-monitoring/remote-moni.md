# Remote Moni

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Remote_Moni.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Remote_Moni.pdf) Hub item 120.

You need two Anytone Radios. 868/878/578

This lets you listen to what is going on around one of your radios.
Just like a Baby Monitor.

**Turn on in the CPS**
CPS Select: **Optional Setting → Digital Function → Remote Monitor = ON**

Only works on DMR.

## How to use

Turn on Remote Monitor on Both radios as shown above.
You need to have the other Radio ID number in your Contact/Talk Group list as Private Call
Hit List Key (RED)
Scole to find the other radio.
Select Key (Green)
Select View Contact
Options
Select Remote Moni

Radio will send request and link to other radio.

To unlink. Turn your radio OFF and ON
