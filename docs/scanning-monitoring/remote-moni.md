# Remote Moni

!!! info "Source"
    Originally published by Norman Williams on hamradiosouthernrepeaters.co.uk. [Original PDF](../originals/images/Anytone/Remote_Moni.pdf) · [Source](https://hamradiosouthernrepeaters.co.uk/images/Anytone/Remote_Moni.pdf) Hub item 120.

You need two Anytone Radios (868/878/578).

This lets you listen to what is going on around one of your radios, just like a Baby Monitor.

!!! note
    Only works on DMR.

## Turn on in the CPS

**CPS → Optional Setting → Digital Function**

| Setting | Value |
|---|---|
| Remote Monitor | ON |

## How to use

1. Turn on Remote Monitor on both radios as shown above.
2. You need to have the other Radio ID number in your Contact/Talk Group list as Private Call.
3. Hit **List** Key (RED).
4. Scroll to find the other radio.
5. Select Key (Green).
6. Select View Contact.
7. Options.
8. Select Remote Moni.

Radio will send request and link to other radio.

To unlink, turn your radio OFF and ON.
