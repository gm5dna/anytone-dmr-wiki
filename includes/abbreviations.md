*[CPS]: Customer Programming Software: the Windows program used to program the radio
*[TG]: Talk group: a DMR group channel such as 2350 (UK)
*[TGs]: Talk groups: DMR group channels such as 2350 (UK)
*[TS]: Time slot: each DMR repeater frequency carries two time slots (TS1 and TS2)
*[TS1]: Time slot 1
*[TS2]: Time slot 2
*[CC]: Colour code: DMR's equivalent of a CTCSS tone (0–15)
*[MCU]: Microcontroller unit: the radio's main processor
*[NXDN]: Next Generation Digital Narrowband: a digital mode supported by the AT-D890UV
*[APRS]: Automatic Packet Reporting System: position and messaging
*[VFO]: Variable frequency oscillator: free tuning, not a stored channel
*[CTCSS]: Continuous Tone-Coded Squelch System: sub-audible analogue access tone
*[DCS]: Digital-Coded Squelch: digital alternative to CTCSS
*[PTT]: Push to talk
*[TOT]: Time-out timer: limits the length of a single transmission
*[STE]: Squelch tail elimination
*[BER]: Bit error rate: used to calibrate hotspot offsets
*[MMDVM]: Multi-Mode Digital Voice Modem: the board inside most hotspots
*[DTMF]: Dual-tone multi-frequency: keypad tones
*[RSSI]: Received signal strength indication
*[CSV]: Comma-separated values: spreadsheet file used to export and import codeplug data
*[BM]: BrandMeister: worldwide DMR network
*[TNC]: Terminal node controller: packet radio modem
*[KISS]: Keep It Simple, Stupid: TNC protocol used by APRS apps
*[SSH]: Secure Shell: remote command-line login
*[SFR]: Single-frequency repeater
*[ARC4]: An older, weaker stream cipher, also used for DMR encryption
*[RAS]: Restricted Access to System: Motorola feature that limits which radios can use a system
